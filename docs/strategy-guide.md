# 策略手册与陷阱指南

## 三档接口
1. **声明式 DSL/条件组合**：编译到 C++，无 Python 逐 bar 开销。
   `qc.factor("rank(ts_mean(close,5)/ts_mean(close,20))")`；选股条件组合（价格/量/市值/估值/财务/技术）。
2. **面板模式（推荐）**：`on_rebalance(ctx) -> weights`，或直接返回 `(date × security)` 目标权重矩阵；
   C++ 引擎撮合、记账、费用、trace。
3. **事件模式**：`on_bar/on_event` 批量截面上下文；逐股逐 bar 的 Python 回调禁止进入热路径（允许但标红警告）。

## 策略包
```
strategy.py      # 实现接口
strategy.yaml    # 参数 JSON Schema -> UI 表单
```
- 内容哈希版本化与 diff；运行于独立 worker 子进程（超时/内存限制、默认禁网、禁写工作区外）。
- 导入他人策略需显式确认；沙箱目标是防误操作，不是对抗恶意代码。

## 内置模板（M4 ≥7）
买入持有基准、双均线、动量/反转、低波动、红利质量、小市值+流动性过滤、多因子打分调仓；
V2 增加指数增强、ETF 轮动。每个模板附假设与已知陷阱。

## 五类常见陷阱
1. **未来函数**：用当日收盘后才知道的数据做当日成交；本引擎默认 T 日信号 T+1 成交，`qc check lookahead` 截断重跑检测。
2. **幸存者偏差**：只用当前存续股票；股票池必须含退市/停牌/ST 历史。
3. **过拟合**：样本内参数搜索后直接报告；用 walk-forward、Deflated Sharpe、PBO、成本敏感性验证。
4. **成本/容量不真实**：忽略最低佣金、印花税、滑点、涨跌停/停牌不可成交、成交量约束。
5. **复权误用**：指标用后复权/比率不变序列；绝对价格条件用不复权价；撮合/现金/持仓用原始价+公司行为。
