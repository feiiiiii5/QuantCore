# PRODUCT — QuantCore 产品理念与设计原则

> 状态：2026-11-02（交接后重构轮）。本文是 UI/UX 重构与功能取舍的决策依据。
> 本文只做产品设计与市场观察，不构成投资建议；QuantCore 仍然只做研究与模拟，不做真实下单。

## 1. 我们解决什么问题

个人 A 股研究者的真实困境不是"缺一个回测函数"，而是**一条断掉的链路**：

```
看盘软件里看到异动  →  想验证一个想法  →  不会写代码/不会弄数据  →  放弃
```

即使会写代码，也要跨过四道坎：

| 坎 | 具体表现 |
|---|---|
| 数据 | 行情不全、复权口径不一、停牌/涨跌停/ST 细节缺失、PIT 财务难对齐 |
| 环境 | Python/数据库/依赖/编译，装好就劝退；云平台又要求上传策略与数据 |
| 可信 | 回测漂亮但换样本就崩；忽略成本、未来函数、过拟合；不知道结果能不能信 |
| 决策 | 回测结果与当下行情割裂，看完不知道该做什么，也不会解释给用户自己听 |

市场扫描（2026-11 常见工具形态，均为公开产品观察，非评测结论）：
- **看盘类**（同花顺/东方财富/TradingView）：行情强、研究弱，回测与复现不是一等公民；
- **云量化平台**（聚宽/米筐/BigQuant 等）：能力全但要求编程与云端数据，初学门槛高、隐私弱；
- **本地终端类**（QMT/miniQMT/PTrade 等）：偏交易通道与专业用户，环境/权限门槛高，且涉及实盘风险；
- **通用回测库**（backtrader/vectorbt 等）：灵活但只是库，不是可用的产品闭环。

调研来源（检索时间 2026-11-02）：[QMT vs PTrade 散户量化工具对比](https://cloud.tencent.cn/developer/article/2659413?policyId=1004)、
[HolisticaQuant 智能投研系统](https://chinaxiv.org/user/download.htm?uuid=666d66ce-f047-4e91-bec6-46d9c40c6d44&filetype=pdf)、
[Fintech/交易 UI 设计实践](https://github.com/khalid-naami/khalid-naami.github.io/blob/main/blog/2026-05-07-html-css-fintech-guide.md)。
这些资料的共同结论被吸收为设计输入：**新手在"数据→策略→验证→解读"链路上流失最多**。

## 2. 产品理念

> **让每个 A 股散户都能做"可复现、可解释、可比较"的研究。**

不是"又一个回测工具"，而是一条**从想法到证据的闭环**：

```
看到（实时市场） → 想到（策略/假设） → 验证（真实数据回测） → 读懂（结论卡片 + 可信度） → 下一步
```

三条产品支柱：

1. **看得懂**：结论先行。首屏回答"今天市场怎么样 / 我的关注怎么样 / 我该做什么"，
   而不是先给一堆表单和控件。
2. **跑得通**：零基础 3 步。内置一键示例数据 + 中文引导 + 术语解释 +
   默认即可用的策略模板；任何页面都有"下一步"。
3. **信得过**：每个结果都带"数据体检"与"可信度"标签——数据覆盖/缺口/复权一致性、
   交易成本、样本外、过拟合提示；宁可显示"数据不足"，也不给假结论。

## 3. 差异化：三个具体设计

### 3.1 研究卡片（Research Card）
一次回测 = 一张卡片，包含：**假设**（策略一句话解释）、**数据**（快照/区间/体检徽章）、
**结果**（收益/回撤/夏普/换手，带成本后口径）、**可信度**（样本外/过拟合/成本敏感性）、
**下一步**（换参数再跑 / 加入对比 / 导出报告）。
用户不需要读懂所有指标，也能判断"这个结果值不值得继续看"。

### 3.2 数据体检（Data Health）
数据页与每个结果页展示体检结论：覆盖率、缺口明细、OHLC 自洽、涨跌停校验、
复权连续性、跨源抽样校验。**数据可信是回测可信的前提**；
导入真实数据后如果没有通过体检，结果页会明确降级提示。

### 3.3 行情 → 研究直连
行情页/首页的任意证券或板块可一键"用当前标的发起研究"，自动带入标的与区间，
把"看盘"和"验证"接成同一条路径。

## 4. 用户与场景

| 角色 | 目标 | 我们提供的路径 |
|---|---|---|
| 小白（0 基础） | 5 分钟看到第一份回测 | 一键示例 → 引导卡片 → 解释型结果页 |
| 进阶爱好者 | 验证想法、比较参数 | 模板/DSL → 参数扫描 → 实验对比 → 稳健性 |
| 半专业研究者 | 数据可信、可复现 | 数据体检 → 快照/实验复现 → 成本/样本外 |

新手模式（默认开）与专业模式共用同一套页面：新手模式隐藏高级参数、
把术语换成白话、突出"下一步"；专业模式展示全部字段与导出。

## 5. 成功标准（本地可验证）

- 首次用户从启动到看到第一份回测结果 ≤ 5 分钟（一键示例 + 引导）。
- 主要任务点击数：看市场结论 ≤ 1 次点击（首页）；发起回测 ≤ 3 次点击。
- 每个结果页在 1 屏内给出：结论、数据来源与体检、可信度、下一步。
- 数据不完整/不可信时，UI 必须显式标注，而不是静默出结果。
- 所有页面 loading/empty/error/无数据可解释；键盘可达；深浅色对比度达标。

## 6. 非目标（明确不做）

- 不做真实下单/券商连接；`BrokerGateway` 保持禁用。
- 不做云托管、不上传用户策略/数据。
- 不承诺收益、不把合成数据/研究近似包装成真实市场结论。
- 不追求"指标最多"；优先"结论可读、证据可信"。
