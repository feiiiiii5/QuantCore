# engine-semantics — 回测语义（实现前先定稿，测试逐条引用）

> 原生引擎：0.1.1。规则来源与核对日期见 `rules-sources.md`；未核实项标 TODO(verify)。

## 1. 时序
- T 日收盘后，用 ≤T 的数据产生目标权重；T+1 按 ExecutionModel 成交。
- ExecutionModel：`next_open`（默认）、`next_close`、`next_vwap`（成交额÷成交量）、`after_hours_fixed`（15:05–15:30 收盘价）。
- 日线无法确定的日内先后顺序，采用保守假设：同一调仓日先卖后买、先资金校验后成交；报告中注明。
- 生产回测使用 C++ 撮合与账本；模拟账户目前使用独立的 Python 撮合实现，能力范围见 `paper-trading.md`。

## 2. 规则基线（V1 沪深主板日线现货多头）
- 涨跌幅：主板 ±10%；ST/*ST 在 2026-07-06 前 ±5%、自该日起 ±10%（TODO(verify)）；新股/退市整理期特例 TODO(verify)。
- 基准价 = 前收盘；除权除息日用除权参考价；限价四舍五入到分。
- 申报：买入 100 股整数倍；卖出余量不足一手可一次性卖出；最小价位 0.01 元。
- T+1：股票买入当日不可卖。
- 盘后固定价格交易：15:05–15:30 以收盘价撮合；沪深 2026-07-06 起扩展至全部 A 股与 ETF（TODO(verify)）。
- 一字板/停牌不可成交；涨停买入、跌停卖出按“可成交掩码+流动性约束”保守处理，给出拒绝原因码。
- 费用：佣金（费率+每笔最低 5 元，可配）；印花税（仅卖出 0.05%）；过户费（0.001%，适用市场 TODO(verify)）；经手费/证管费（TODO(verify)，配置化）。当前分红按税前现金处理；回测窗口内存在现金分红时请求 `enable_dividend_tax=true` 会明确报错。
- 复权：撮合/现金/持仓用原始价 + 公司行为事件；指标默认后复权或比率不变序列；绝对价格条件用不复权价；图表可前复权。
- 资金：卖出款当日可用于买入；退市/长期停牌按配置处理（强制清算价/归零）。
- 年化交易日默认 244；无风险利率常数/序列、基准类型均在报告标注。

## 3. 账本不变量（每步断言）
1. 净值守恒：现金 + 持仓市值 = 初始资金 + 已实现盈亏 + 浮动盈亏 + 分红 − 费用与税。
2. 现金 ≥ 0；可卖数量 ≤ 持仓；不违反 T+1。
3. 每笔费用可复算（佣金、印花税、过户费、经手费、证管费）。
4. 成交价在当日 [low, high] 内（盘后固定价除外）；涨停买入/跌停卖出被拒绝。
5. 持仓批次、成本价、已实现盈亏可逐笔追溯。

## 4. 防未来函数
- 数据访问器只返回 ≤now 的数据；`qc check lookahead` 用“截断数据重跑、信号不变”自动检测。

## 5. 公司行动与历史兼容
- 默认读取 Panel/Snapshot 的现金分红与送转事件，按当前证券顺序映射到 C++；在 `ex_date` 开盘前调整持仓、成本与现金。现金在除息日记账，尚未模拟实际派息日到账或个税。
- 除权日缺报价时同步调整上一估值与参考价；连续停牌期间多次事件继续复合。卖出胜率与盈亏比使用真实账本的 FIFO 已实现盈亏，包含买卖费用；分红计入净值，不计入卖出价差胜负。
- `use_panel_corporate_actions=false` 关闭面板事件；显式 `corporate_actions` 按 `(sec_id或sec, ex_date)` 覆盖同一面板事件。配股认购尚未实现，窗口内存在正 `rights_ratio` 时明确报错。
- 新实验保存事件开关。历史实验配置缺少该开关时，重播与沿用配置按旧版本的忽略事件行为恢复；跨版本的其它结果变化仍会被 replay 报告。

## 6. 基准
- `benchmark_code` 选择本地证券；首个有效收盘价买入可分割份额，之后持有，分红留作现金，送转调整份额。不计手数、交易成本、税或分红再投资，使用与策略相同的生效事件配置。
- 报价缺失处曲线留空；跟踪误差与信息比率只用连续两天都有报价的日收益，配对样本不足时为 `null`。区间首尾报价缺失时不展示超额收益，避免把不同区间当作同一结果比较。
