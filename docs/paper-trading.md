# 模拟交易（Paper Trading）模型

本地虚拟账户有**历史快照回放**与**实时行情模拟**两种模式。均仅研究与模拟，不连接券商、不发送真实委托。
撮合仍在 Python 层；生产历史回测使用 C++20 `qcore`。

## 模式与数据

| 模式 | 数据 | 推进与成交触发 |
|---|---|---|
| `historical`（默认） | 不可变本地快照；合成数据标为 `SYNTHETIC` | `step()` 前进交易日并用当日 OHLCV；支持历史模拟时钟 |
| `live` | 显式开启网络后的公开报价；无需快照 | `POST /api/paper/sessions/{id}/refresh` 更新估值并尝试成交；不支持历史 `step`/`auto` |

价格为元（CNY），最小价位默认 0.01 元（`rules.min_price_tick`）；股票成交量为**股**，不是手。
模式写入 `config.mode`，列表与详情显示 `session.mode`；旧 JSON 缺少模式时按历史处理。
实时账户可离线创建，但未开启行情时不会成交；最多同时关注 50 只持仓或未完成委托证券。

## 实时行情模拟

模拟页打开且选中实时账户时，UI 每 3 秒发送刷新；也可手动刷新或直接调用 API。
**只有实际刷新请求才撮合**。关闭页面后，行情轮询服务本身不会推进账户；没有后台无人值守交易。

一次刷新遵循以下条件：

1. 行情已开启；逐证券报价有有效源时间戳、有效价格和成交量，且未标陈旧/停牌。
   报价年龄不超过 15 秒，不能超前本机时间超过 2 秒；重复或倒退时间戳不再使用。
2. 连续交易时段才撮合，其他时段保留委托。跨日首次开市刷新释放既有持仓可卖数量，保持 T+1。
3. 下单后先观察成交量基线，随后才消费新报价。相邻有效观察须同源、同日且间隔不超过 30 秒，
   预算为 `floor(max(0, 新累计量 − 同证券当日共享高水位) × participation)`，默认 10%。股票成交量均归一为股，所有来源共用一个高水位。
   首次观察、换源、跨日或观察间隔过长只重建基线；累计量回拨保留共享高水位，落后来源恢复到已计数区间时不再分配预算，可能保守少成交。高水位随账户保存，跨日清零；旧 `source_volumes` 以全部已保存计数的最大值迁移，未保存的更早历史无法逆向恢复。
4. 同一证券订单按保存顺序共享一次预算；新报价必须晚于订单创建时间。
   市价单用最新报价；限价单还需最新价触及限价。买涨停/卖跌停不假设可成交；缺少有效边界时等待。
5. 买单按手数向下取整，卖单受可卖数量限制；每笔成交与新观察基线一起持久化。

缺少新鲜度、基线、增量或限价条件时保留委托，显示等待原因。无盘口、报价深度、排队、滑点、冲击成本
或成交概率模型；累计量只是容量近似，不证明真实可成交。换源、断线或稀疏刷新可能少成交。
权益曲线每天保留最新估值，不是完整盘中曲线。

## 历史回放成交规则

- 委托在提交后的下一交易日尝试成交（`order.date < current_date`）。
- 市价单用次日开盘价，受当日 high/low/涨跌停夹取。
- 限价单：买入在 `low <= limit` 时触发，价格为 `min(open, limit)`；卖出在 `high >= limit` 时触发，
  价格为 `max(open, limit)`；未触发保持待成交。
- 停牌、开盘涨停买入/跌停卖出、一字线或无有效报价时，按现有历史规则拒绝订单。
- 无盘中顺序或盘口模型，仅用日线数据。

历史订单每个交易日最多成交 `floor(volume × participation)`，默认 0.1；这是**逐订单**上限，
不同于实时模式同一证券共享增量预算。剩余量为 `qty − filled_qty`。买单取整后不足一手（或 STAR/BSE 最低量）
保持待成交，卖单不整手且不超过可卖量。成交不足为 `partial`，后续交易日继续尝试。
现金不足或后续触发拒绝规则时，剩余部分拒绝，已成交明细保留；到结束日未完成不强制成交。

## 历史模式的公司行为

历史账户从同一不可变快照读取事件，在进入 `ex_date` 的交易日、释放 T+1 可卖数量和尝试委托之前处理：

- 现金按除权前股数计发，采用**税前、除权日即时入账**近似，不按 `pay_date` 延后，不计算分红个税。
- 送转按每个已记录买入批次分别乘比例、四舍五入到股（正数半股向上），沿用原生数量近似；
  总成本按既有六位小数均价精度保留，除权估值为 `(旧估值 − 每股现金) / 送转比例`。
  持续停牌时不以旧有限收盘价覆盖已调整估值，复牌新收盘价再更新。
- 受影响证券除权日前的 pending/partial 委托取消剩余部分，已成交明细保留；按除权后价格和股数重新下单，
  不替用户自动改价改量。除权日之后新买入的股份不追溯领取本次权益，并继续受 T+1 限制。
- `positions[].lots` 保存买入批次数量，卖出按 FIFO 扣减数量以保留后续取整依据；这不把原有加权均价成本模型改成原生 FIFO 成本模型。
- `corporate_events` 随账户持久化，记录日期/证券、现金、前后股数、取消的订单 ID 和近似模型；同一日期/证券不重复应用。
  reset 清除此记录并从初始现金重新回放。
- 非有限/负现金、非正或非有限送转比例、配股认购，以及有现金事件时请求未实现的分红税，会明确拒绝。
  当日先验证全部待处理持仓，再修改当日账本；不承诺整次多日 step 的数据库回滚。

旧文件缺少 lots 时只能把现有股数视为一批，无法恢复已经遗失的逐笔取整历史。
**已越过除权日的旧账户不自动补账**：新增支持只处理后续推进的日期；如需完整新口径，应重置并重新回放，
或新建账户。缺失的历史现金/持仓记录不猜测恢复。
实时账户没有公司行为事件 feed，仍不调整分红、送转或除权；不能把历史模式的支持扩展到实时模式。

## 账户、手数与费用

- 保存现金、持仓（qty/available/avg_cost/last）、订单、逐笔成交、权益曲线。
  `equity = cash + Σ(qty × last)`；历史模式按收盘价估值，实时按有效新报价估值。
- 买入新增股份当日不可卖；历史模式下一交易日、实时模式下一交易日开市刷新后释放。
  卖单不得超过 `available`。
- 买入手数复用 `paper/rules.canonical_buy_qty`：MAIN/GEM 为 100 股整数倍；STAR 最少 200 股、1 股递增；
  BSE 最少 100 股、1 股递增；历史模式的 ETF 为 100 份整数倍，可转债为 10 张整数倍。
  实时模式按 A 股股票代码识别，不宣称完整 ETF/债券实时规则。卖出不要求整手。
- 逐笔分别计佣金（含最低 5 元）、仅卖出印花税、沪市过户费和交易所/证监规费，复用
  `paper/rules.fee_breakdown` 与 `CostModelConfig`。模型可配置，待核实细节见 [规则来源](rules-sources.md)。
  部分成交可能多次收最低佣金；`order.fees` 为累计，`trades[].fees` 为单笔。
- `avg_cost` 与累计成交均价按 6 位小数保存，旧文件丢失的精度无法恢复。

参与率配置在会话 JSON 的 `config.execution.participation`，范围 `(0, 1]`，缺省 0.1；非法值初始化时报
`PaperValidationError`。例如：

```json
{
  "config": {
    "mode": "historical",
    "costs": {"commission_rate": 0.0003, "min_commission": 5.0},
    "rules": {"main_lot": 100, "t_plus_one": true},
    "execution": {"participation": 0.1}
  }
}
```

## 订单、持久化与组合

- 状态为 `pending`、`partial`、`filled`、`cancelled`、`rejected`；`pending`/`partial` 可撤单。
- `filled_qty` 为累计量，`remaining_qty = qty − filled_qty`；`fill_price` 为累计加权均价，
  `fill_date` 为最近成交或拒绝日期，`fees` 为累计费用。
- `fills` 保存 `[{date,qty,price,amount,fees}]`，旧 JSON 缺省为空；列表 `pending_orders` 包括 pending 与 partial。
  信号 CSV 使用累计量、加权均价与累计费用。
- 会话逐个加锁，每次修改以原子 JSON 写到 `<data_root>/paper/`，包含实时观察基线。
  重启后仍需有效新报价与增量才成交，不补做离线期间成交。
- 只读多账户组合取权益日期交集，不插值；曲线在首个共同日期重基为 1 后按权重配置资金，
  不因共同区间前涨跌改变配置权重；不回写账户或产生订单。

## 当前范围

两种模式都没有券商通道、真实下单、融资融券/期权/新股申购、盘后固定价格特殊申报或完整资金交收。
历史模式仅支持上述税前除权日近似；实际到账日、分红个税、配股和碎股现金补偿未实现。实时账户没有公司行为事件源，公司行为仍可能使实时持仓值失真。
公开源非授权 L2，可能延迟、断流或变更。涨跌停、停牌、ST、板块及费用仍有近似和待核实项。
参与率是模拟假设，不是交易所规则。

本模块用于本地研究、策略验证与教学模拟；历史表现不代表未来，不构成投资建议。
