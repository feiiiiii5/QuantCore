# UI — 交互与页面

前端 `ui/`：React 19 + Vite + TypeScript；设计令牌在 `ui/src/styles.css`；zh-CN 默认。

## 导航
行情 / 选股 / 策略 / 回测 / 实验 / 数据（+ 设置）；顶部全局搜索（代码/名称/拼音首字母，M6 接入离线索引）；
底部状态栏显示数据截止日、数据源、任务进度、网络。

## 页面
- 行情：指数、涨跌分布、行业板块、自选；K 线（缩放/十字线/多股对比/成交量/换手/指标）。
- 选股：DSL 条件组合、股票池、保存方案、导出。
- 策略：模板、参数表单（JSON Schema）、Monaco、运行日志、版本与 diff。
- 回测：表单 → 排队/进度/取消 → 净值与回撤、指标、持仓、逐笔；点交易联动 K 线；框选回撤区间（M6）。
- 实验：命名/标签/笔记/对比/导出；数据：源配置/下载/质量/导入导出/占用/备份。
- 首次向导：合成示例三步跑出第一回测；真实数据源配置。

## 预算（M6 门禁）
5000 根 K 线缩放平移 ≥60fps；10 万行表格虚拟滚动流畅；首屏 <2s。
